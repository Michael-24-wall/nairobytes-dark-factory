# Factory Stages

The intended lifecycle is Human Requirement, Architect, Builder, Tester, Breaker, Repair, Retest, Verifier, Evidence, Git, GitHub, Human Approval, and Deployment.

The current live implementation provides the requirement/design/asset input boundary and the existing reservation verification evidence. There is no background execution service yet, so the frontend does not fabricate progress, task events, commits, pull requests, or deployments.
